## Featured analysis

In my [BRFSS report](index.qmd), I use data from the CDC’s 2015 Behavioral Risk Factor Surveillance System to explore caregiver status, self-reported mental health, and access to a personal healthcare provider. The report includes data cleaning, charts, and linear and logistic regression. The analysis is exploratory and uses unweighted survey responses.

**Tools and methods:** R, tidyverse, ggplot2, Quarto, data cleaning, exploratory analysis, and regression.

[CDC’s 2015 BRFSS codebook](https://www.cdc.gov/brfss/annual_data/2015/pdf/codebook15_llcp.pdf)
